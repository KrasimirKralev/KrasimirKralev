## 🦞 About me

I'm **Krasimir** — COO at [**IDRobots**](https://idrobots.com) and a full-stack engineer who spends most days at the edge between web apps and on-device AI. Bulgarian, based in **Plovdiv**.

I co-maintain [**ClawBox**](https://github.com/ID-Robots/clawbox) — a private AI assistant that runs entirely on NVIDIA Jetson hardware — and I'm an active contributor to the [**openclaw/\***](https://github.com/openclaw) ecosystem. The rest of my time goes to production websites for real Bulgarian businesses at [krasikralev.com](https://krasikralev.com).

---

## 🚀 What I'm shipping right now

- 🦞 **[ClawBox](https://github.com/ID-Robots/clawbox)** — 50+ PRs in the last 8 weeks: setup wizard with captive-portal AP, Chrome OS-style desktop window manager, MCP server with 40+ tools, OAuth flows for 6 providers. Co-maintainer.
- 🛠️ **OpenClaw OSS contributions** — currently in flight:
  - [`openclaw/lobster#98`](https://github.com/openclaw/lobster/pull/98) — fix for Ajv `.compile()` SchemaEnv leak (memoization, Option 1 from the issue)
  - [`openclaw/openclaw#77820`](https://github.com/openclaw/openclaw/issues/77820) — investigated WhatsApp QR rendering bug; spawned [PR #77844](https://github.com/openclaw/openclaw/pull/77844)
- 🌐 **[krasikralev.com](https://krasikralev.com)** — Astro/Tailwind sites for SMB clients across Plovdiv

## 🤝 How I work with AI tooling

I lean heavily on AI tooling (Claude, Codex, MCP) for OSS contributions and internal automations. **PRs I open to public repos are AI-assisted, reviewed by hand before push, run through local lint/typecheck/tests, and clearly marked `[ai-assisted]` per project conventions.** I'm a real human reviewing every diff — happy to redirect or close if a fix isn't right. Honest disclosure beats pretense.
